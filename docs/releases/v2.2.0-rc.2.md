Предварительная версия для проверки восстановления подключения после региональных отказов Gemini.

- Исправлено определение отказавшего маршрута при закреплении IP в hosts. После регионального отказа запускается повторный выбор доступных адресов.
- Повторная настройка сохраняет рабочие подключения при раннем сбое поиска. Фоновое восстановление и настройка из меню согласуют изменения через общую блокировку.
- Добавлен профиль ARM64 для agy на Mac. Ошибка патча отдельного файла больше не отменяет настройку DNS; отмена операции пользователем по-прежнему останавливает её.
- Добавлен пункт **7. Сохранить диагностику** и команда `report [каталог]`. Отчёт содержит состояние приложения, службы, DNS, маршрутов, проверки кандидатов и события восстановления. Токены, переписки, пользовательские пути и исходные журналы исключены. Отправки данных нет.
- Чтение DNS-конфигурации Mac учитывает выравнивающие пробелы в системном выводе.

После загрузки новой версии выберите **1. Включить обход**, чтобы обновить установленную DNS-службу. Перезапустите Antigravity и проверьте нужные модели реальными запросами.

Для Windows скачайте `antigravity-bypass-russia.exe`. Для Mac скачайте `unlock_and_restore.sh` и запустите из терминала: `chmod +x unlock_and_restore.sh`, затем `sudo ./unlock_and_restore.sh`.

Это кандидат в релиз: автоматические проверки не заменяют проверку на Mac с исходной ошибкой. Для такой проверки нужны запросы к Gemini до и после восстановления, перезапуск приложения и компьютера, смена Wi-Fi и обновление установленной службы. При повторном отказе сохраните диагностику пунктом 7 и приложите файл к Issue #4.
